# Task 2 – Unemployment Analysis with Python

## Objective
Analyse unemployment-rate data, identify trends, examine the COVID-19 period, and produce visual insights that can support economic and social policy discussions.

## Dataset
The project uses:
- `Unemployment in India.csv`
- `Unemployment_Rate_upto_11_2020.csv`

## Technologies
- Python
- Pandas
- Matplotlib
- Seaborn

## What the project does
1. Cleans column names, dates and numeric values.
2. Calculates monthly and regional unemployment summaries.
3. Compares pre-COVID observations with the COVID period.
4. Compares rural and urban unemployment.
5. Creates trend and distribution charts.
6. Exports summary tables to CSV.

## Run
```bash
pip install -r requirements.txt
python main.py
```

Charts and summary files are saved in `outputs/`.

## Key interpretation
The analysis should be interpreted as descriptive evidence from the supplied dataset. A change in unemployment during COVID-19 does not by itself prove that COVID-19 was the only cause.
